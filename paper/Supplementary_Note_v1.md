# Supplementary Note — functional-standard-atlas

Companion to: *No model everywhere: territory-resolved benchmarking of twelve
variant effect predictors against 64,178 saturation genome editing measurements*

All statistics below are read from pipeline output files (AGENTS.md rule 5);
source files are cited per section and are released with the atlas.

---

## S1. Variant mapping and atlas freezing

All 64,178 assay rows (7 MaveDB SGE assays) were mapped to GRCh38 with a
**100.00% success rate** (`results/mapping_report_v1.md`,
`results/mapping_summary_v1.json`). Provenance was fetched live by script and
hash-registered:

- MANE Select transcripts: NCBI MANE GRCh38 v1.5 summary
- Transcript exon models: Mutalyzer3 API (`reference_model/`, per assay accession)
- Genomic exon anchors + reference sequence: Ensembl REST (GRCh38)
- Cross-validation: Ensembl VEP (independent HGVS mapper; dbSNP/ClinVar via
  colocated variants)

Orientation rule (recorded per assay):
`functional_pathogenicity = −score` (SGE raw score: higher = more normal function).

Coordinate conventions: GRCh38; `pos` 1-based; indels left-anchored VCF-style
(ref = anchor + deleted, alt = anchor + inserted); alleles on the + strand.

Per-assay mapping: BRCA1 3,893/3,893; BRCA2 6,959/6,959; BARD1 10,911/10,911;
PALB2 12,851/12,851; RAD51C 9,188/9,188; VHL 2,268/2,268; BAP1 18,108/18,108.

## S3. GPU scoring runs (NT-v2-500M and Evo2-7B)

Both foundation models were scored on a rented NVIDIA A6000 (48 GB) cloud
instance under tmux, with append-only TSV score caches for crash resumability
(runbook: `cluster/RUNBOOK_GPU.md`; environments pinned in
`models/{nt,evo2}/requirements.txt` with full `pip freeze` archives
`pipfreeze_runpod.txt`).

- **NT-v2-500M**: masked 6-mer LLR, 6,000-bp window, transformers 4.46.3 /
  torch 2.11.0+cu128; 46,392 SNVs scored; output `results/nt_scores.parquet`.
- **Evo2-7B**: windowed LL delta (LL REF − LL ALT), 8,192-bp window,
  evo2 0.6.0 / torch 2.7.1+cu128 / flash-attn 2.8.0.post2, bf16;
  46,392 SNVs scored in 25.0 h wall time (5,024 batches, batch size 8);
  output `results/evo2_scores.parquet`.
- AlphaGenome API validation report: `results/ag_test_report_v1.md`.

Skipped (unscored) variants: FASTA reference-base mismatch; ambiguous (N)
bases in window; windows truncated below 1 kb at chromosome ends.
